# 复现运行说明

## 环境

Python 3.12；numpy==2.5.3、scipy==1.18.1、pandas==3.0.1、openpyxl、matplotlib==3.11.1、python-docx、lxml、latex2mathml==3.81.1、pymupdf==1.28.2。数值计算只需要前四项。相对路径以src/model.py所在位置解析。

## 数值复现

在本目录执行：

```powershell
python src/run.py --stage all
python src/review_results.py
python src/q1_certificate.py
python -c "import sys; sys.path.insert(0,'src'); from deliver import causality; causality()"
```

all包括问题1、预测与选型、12组全年策略、24日敏感性。已有年度npz会缓存；要强制重算年度，使用--stage annual_force。run.py不会覆盖工程根目录五份原表。review_results.py把工程根目录的原表作为只读比较对象，若移动整套工程须保持原表路径关系。

## 文档与表格

figures.py生成15幅支持图；build_review_paper.py生成修订论文，依赖已完成的数值文件和q1_certificate.py输出。word_math.py使用LaTeX→MathML→OMML，并借助Microsoft Office的MML2OMML.XSL；Windows Word用于实际渲染。论文公式源保存在05_论文中。

revise_workbooks.mjs使用@oai/artifact-tool导入原表，修正末段标签并增加费用核算。需设置RUNTIME_NODE_MODULES指向可用的托管包目录。这里不依赖原有deliver.py的Excel写入路径。

src/paper.py、src/equations.py、src/pack.py及render_word.ps1是原流程的历史副本，保留用于审查，不作为修订版默认运行入口；其中可能含原机器路径或旧格式。原代码完整副本位于00_原始文件清单/原代码，便于对照。

## 输出与检验

results保存逐时段NPZ、逐日费用CSV、选型结果与指定日期JSON；audit保存输入哈希、物理费用和因果检查。q1独立模型输出另存计算结果。qa_revision.py验证五份修订表的原有数值未变、公式结构正确以及原文件哈希不变。使用--render对Word导出PDF逐页生成图像。

不执行历史pack.py；不将依赖目录、node_modules、inspect.ndjson或渲染PNG当作正式支撑材料打包。
